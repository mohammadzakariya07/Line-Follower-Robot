# 🤖 Line Follower Robot using Arduino (5 IR Sensors)

## 📌 Overview
This project implements a **Line Follower Robot** using **Arduino**, a **5-channel IR sensor array**, and a **dual motor driver**.  
The robot automatically follows a black line on a white surface by analyzing sensor inputs and controlling motor direction and speed.

---

## ⚙️ Features
- 5 IR sensors for accurate line tracking  
- Handles straight paths, curves, and sharp turns  
- PWM-based motor speed control  
- Emergency stop using near sensor  
- Simple and beginner-friendly logic  

---

## 🧠 How It Works
- IR sensors detect the line position
- Arduino processes sensor values
- Motor driver adjusts motor direction
- Robot follows the line continuously
